## 🧰 Vitool Box

| App | What it does |
| --- | --- |
| 📊 [**Vela System Monitor**](https://github.com/VitomDev/Vela-System-Monitor) | CPU, RAM, disk, network and battery in the tray, with a floating widget and taskbar view |
| 🎨 [**Iro Color Picker**](https://github.com/VitomDev/Iro-Color-Picker) | Pick any color on screen with a pixel-exact magnifier — HEX, RGB, HSL, HSV, CMYK |
| 🔳 [**Kodo QR Instant**](https://github.com/VitomDev/Kodo-QR-Instant) | Read QR codes from any screen region and create them from the clipboard |
| 📄 [**Leaf Markdown**](https://github.com/VitomDev/Leaf-Markdown) | Opens `.md` files beautifully rendered, like a PDF reader for Markdown |
| 🖼️ [**Iris Image**](https://github.com/VitomDev/Iris-Image) | Convert images to PNG, JPG, WebP, ICO and more from the Explorer context menu |
| 🎬 [**Mura Converter**](https://github.com/VitomDev/Mura-Converter) | Download and convert video or audio to MP4, MP3, M4A, Opus or WAV |

⚡ Native, lightweight and offline-first · 📦 One-click installers in each repo's Releases · 📄 MIT licensed
